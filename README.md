# zS8-Rat - Fresh FastAPI Backend

Clean, high-performance API rebuilt with **FastAPI** for perfect Vercel deployment.

## Quick Start

### Local
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### Vercel
- Connect repo to Vercel
- Add env vars if needed
- Auto deploys on push

## Endpoints
- `GET /` - Welcome
- `GET /health` - Health check
- `POST /items/` - Example CRUD
- `GET /status` - System status

**100% Vercel Optimized!** 🚀
